# Default map location per company, Indonesian region data, demo data on 8080

Status: done
Ledger: `docs/plans/INBILS_OMP_BACKLOG.md` → "ISP roadmap lanes (2026-10-12)" row `map-default-region`
Source: owner request 2026-10-14: "kasih buat setting default maps lat long atau wilayah misal default surakarta atau jakarta selatan, serta pada inbils lakukan db seed biar saat saya mencoba juga ada datanya langsung untuk melihat" and "untuk provinsi dll belum ada datanya". The owner delegates design decisions ("anda sebagai saya"); decisions D1–D8 are the assistant's.

## Facts (2026-10-14)

- Maps on the web: `Components/ui/MapPicker.tsx` (hardcoded Indonesia `-2.5489, 118.0149`, zoom 5; used by Customers/Create, CustomerAddresses/Index, composite/CustomerAddressEditor), `Components/composite/LatLngMapPicker.tsx` (default `JAKARTA_CENTER` from `latLngMapPicker.helpers.ts`; used by Customers/Create, CustomerAddresses/Index), `Components/composite/locations/LocationsMapView.tsx` (`INDONESIA_CENTER`, falls back to it when there are no markers).
- `HandleInertiaRequests` shares `company.settings` (raw json). Company settings are edited on `admin.company.settings.edit` via `UpdateCompanySettingsRequest` (`settings.*` keys) and `CompanyService::updateSettings`. Resolution rule: `CompanyService::setting(key)` → `SettingService::get('default_'.key)` → hardcoded.
- Region tables `indonesia_provinces/cities/districts/villages` (laravolt/indonesia ^0.41) are empty in the dev DB and on 8080. The package ships CSVs (cities with lat/long, stored in `meta` json) and `php artisan laravolt:indonesia:seed`. `E2eFixtureSeeder::seedIndonesiaRegions` seeds only a small subset for E2E.
- `DatabaseSeeder` runs RolePermission + SystemSetting always, and the demo seeders only in local/development/testing. 8080 runs `APP_ENV=local` and had 0 customers.
- Demo data (`database/seeders/Demo/LocationDemo.php`) sits in Kota Bandung (city code 3273, `-6.9192, 107.6366`). Examples from the owner: Kota Surakarta 3372 (`-7.5579, 110.8231`), Kota Administrasi Jakarta Selatan 3174 (`-6.2726, 106.8100`).

## Decisions

- **D1 Keys.** Company settings `map_city_code` (string|null, an `indonesia_cities.code`), `map_lat`, `map_lng` (numeric, lat −11…6, lng 94…142: Indonesia's bounding box), `map_zoom` (int 3…18). System defaults in the `settings` table via `SystemSettingSeeder` (`firstOrCreate`, keeps edits): `default_map_lat` −2.5489, `default_map_lng` 118.0149, `default_map_zoom` 5 (today's behaviour).
- **D2 Choosing.** Company Settings page gets a "Peta" section: a searchable select "Wilayah default" listing every kota/kabupaten ("KOTA SURAKARTA — Jawa Tengah"); picking one fills lat/lng from the city's coordinates and zoom 12. The admin may instead type lat/lng or click the map (`MapPicker`) and set the zoom; a manual edit keeps the chosen city label only if the point stays inside it — simpler rule: a manual lat/lng edit clears `map_city_code`. Saved with the existing settings form; audit as today.
- **D3 Server-side resolution.** `HandleInertiaRequests` adds `company.map = {lat, lng, zoom, city_code, city_name}` resolved by one helper `CompanyService::mapDefault(?Company)` (company settings → system defaults → hardcoded). `city_name` from `indonesia_cities` only when `map_city_code` is set (one indexed lookup, cached per request).
- **D4 Consumers.** New hook `resources/js/hooks/useMapDefault.ts` returns `{center: {lat, lng}, zoom}` from `company.map` with the Indonesia fallback. `ui/MapPicker` gains `defaultCenter?`/`defaultZoom?` props (stays props-only); every caller passes the hook's values. `LatLngMapPicker` callers pass `defaultCenter` from the hook; `JAKARTA_CENTER` is removed. `LocationsMapView` uses the hook for the no-marker view and the "reset view" button. Existing points (a customer address with lat/lng) still win over the default.
- **D5 Region data seeding.** New `database/seeders/IndonesiaRegionSeeder.php` calls the laravolt `DatabaseSeeder` only when `indonesia_provinces` holds fewer than 38 rows or `indonesia_villages` is empty, so re-seeding is a no-op. `DatabaseSeeder` calls it in every environment except `testing` and `e2e` (they use the E2E subset; a full seed adds ~80k village rows to every E2E reset). This is reference data, allowed by the initialization rule. Deploy line: `php artisan db:seed --class=IndonesiaRegionSeeder --force`.
- **D6 Demo company.** `DemoUserSeeder` sets the demo company's `map_city_code` 3273 (Kota Bandung), `map_lat/lng` from the CSV, `map_zoom` 12, so the demo maps open where the demo data is. Only when the keys are absent (never overwrite an owner edit).
- **D7 Setup Wizard.** Unchanged; a new company starts with the system default (all of Indonesia) until an admin picks a region.
- **D8 Seeding 8080 for the owner.** Run on the 8080 stack (APP_ENV local): `migrate --force`, `RolePermissionSeeder`, `SystemSettingSeeder`, `IndonesiaRegionSeeder` (or `laravolt:indonesia:seed` before the class exists), `DemoUserSeeder`, `DemoDataSeeder`, `CustomerDemoSeeder`. Not `E2eFixtureSeeder` (test fixtures would clutter the demo). Also seed the regions in the Sail dev DB.
- **D9 Demo team (owner, 2026-10-14).** New `database/seeders/DemoTeamSeeder.php` tops the DEMO company up to five active people with an active employee profile per role: admin 5 (demo admin gets an INB-HQ profile + 4 new), manager 5 (+4), staff 5 (+2, with Dewi and Rizky from DemoDataSeeder), technician 5 (+1, with demo technician, Agus, Dedi, Yoga; Hari stays terminated). Emails `<first>.<last>@demo.inbils.test`, the demo password constant of `DemoUserSeeder::PASSWORD`, units fitting the role, numbers INB-03xx admins, INB-04xx managers, INB-0203/0204 staff, INB-0104 technician. Idempotent (`updateOrCreate` by email, `firstOrCreate` profile by user); skips with a console line when the DEMO company or units are missing. Called from `DatabaseSeeder` after `DemoDataSeeder`; deploy `php artisan db:seed --class=DemoTeamSeeder --force` (local/demo only, refuses production).

## Testing decisions

- Feature: settings update validates the four keys (out-of-range lat/lng 422, unknown city 422, zoom bounds), saving a city stores its coordinates as sent; shared prop resolution (company override, system default, hardcoded fallback, `city_name` resolved); `IndonesiaRegionSeeder` is a no-op when data exists (seed a minimal set, assert the laravolt seeder is not called — or count unchanged); `DemoUserSeeder` sets Bandung only when absent.
- Frontend: `useMapDefault` fallback selfcheck (pure helper); E2E: Company Settings → pick "KOTA SURAKARTA" → save → open Customers/Create map → center near Surakarta (read the Leaflet map center via `page.evaluate` on the container's `_leaflet_map` or a `data-center` attribute the picker exposes). The E2E subset seeder must include Kota Surakarta and Kota Administrasi Jakarta Selatan cities (add to `E2eFixtureSeeder::seedIndonesiaRegions`).
