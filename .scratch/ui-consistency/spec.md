Status: ready-for-agent
Ledger: `docs/plans/INBILS_OMP_BACKLOG.md` → "ISP roadmap lanes (2026-10-12)" row `ui-consistency`
Source: owner request 2026-10-14 (grill-me): "list tanggal yang masih input manual, yang masih menulis reference id / product id manual yang tidak langsung ambil dari tabel biar valid, belum konsistensi bahasa Indonesia semua content atau tulisan di web, masih belum memakai dropdown search, ada status yang belum dipakai badge". ## Audit (2026-10-14; full tables in agent outputs AuditDatesIds, AuditLanguage, AuditSelectsBadges)

- **Dates typed by hand (13):** single dates: Tagihan Tanggal Terbit/Jatuh Tempo (`Billing/Invoices/Create.tsx:96,103`), SPK Tanggal Jadwal (`SPK/Create.tsx:153`), Karyawan Tanggal Masuk (`Employees/Index.tsx:303`), Permintaan Barang Tanggal Dibutuhkan (`Inventory/Requests/Create.tsx:171`), Aset Jaringan Tanggal Beli/Garansi (`NetworkAssets/Create.tsx:185,198`, `Edit.tsx:206,219`), Kendaraan Tanggal Beli (`Vehicles/Index.tsx:167`); month: Generate Tagihan Periode (`Billing/Invoices/GenerateDialog.tsx:76`); time: WhatsApp jam tenang (`Company/Settings.tsx:348,359`). Backend rules are plain `date`.
- **IDs typed by hand (6):** Tiket Handler ID (`Tickets/Show.tsx:455`, the `handlers` prop already exists), Kartu Stok Product ID (`Reports/StockCard.tsx:148`, no server validation; location only via URL), Audit Log ID Pengguna (`Reports/AuditLog.tsx:755`, no validation), Permintaan Barang ID SPK/Tiket (`Inventory/Requests/Create.tsx:202`), Evaluasi Reference ID (`Evaluations/Create.tsx:89`), Kategori Parent ID (`Inventory/Categories/Index.tsx:223`).
- **DB-backed selects without search: 33**, every list an unbounded `->get()`; `SearchSelect` filters client-side only and clears the value on typing (bug).
- **Language:** no `lang/` directory, locale `en`; every Create/Edit page and several reports in English; auth pages English; shared table/pagination/export/search/delete strings English; ~110 English flash messages vs ~12 Indonesian; English notification subjects; raw enum values (Individual/Company, snake_case statuses).
- **Statuses:** 19 values rendered as plain text, ~50 badges showing raw codes, 7+ divergent status→tone maps, no label maps for SPK, tickets, assets, ODN ports, IP addresses, employees, vehicles, stock movements, adjustment requests.

## Decisions

- **Q1 Single date and date-time:** `ui/DatePicker` and `ui/DateTimePicker`, same look and typing rules as `DateRangePicker` (company `date_format`, Indonesian, calendar popover), ISO to the server. No native `type="date"` left in the web.
- **Q2 No typed ids:** every reference to another record is picked from its table, showing code + name; the server validates `exists` scoped to the company. Report filters that took raw ids become pickers.
- **Q3 Searchable selects:** DB-backed lists always searchable; fixed enums ≤ 7 options may stay a plain select. Large tables (customers, subscriptions, products, locations, network assets, users/employees, ODN ports) search on the server (≥ 2 characters, ≤ 20 results); small catalogues (categories, units, packages, profiles, SLA tiers, vehicles, organizations, warehouses, POPs, VLANs, ticket categories, document types) use client-side `SearchSelect` with the full list.
- **Q4 Bahasa Indonesia everywhere:** titles, labels, placeholders, buttons, table headers, empty states, dialogs, toasts/flash, validation (locale `id` + `lang/id`), enum/status labels, CSV/PDF export headings, e-mail and notification subjects/bodies, login/forgot/reset/verify/2FA pages. Kept terms: SPK, ODN, ODP, OLT, PON, NAS, IP, CIDR, MAC, VLAN, SLA, MRR, KPI, SKU, RADIUS, Midtrans, WhatsApp, 2FA, Email (label "Email"), STOP (WhatsApp opt-out keyword). Code, route names, database values unchanged.
- **Q5 Status badges:** one map per domain in `resources/js/lib/statuses/` (value → Indonesian label + tone); every status/state/type/priority shown in tables, details, cards and filter options goes through it; the 7+ copies are deleted.
- **Q6 Web only.** API labels unchanged unless an API resource returns a display string (none found).
- **Q8 E2E specs** are updated to the new text in the same ticket as the change; no hidden test attributes added for this.
- **Q9 Report filter validation (security):** Stock Card, Audit Log, Stock Movements, Invoices customer filter, Sales acquirer, Dispatch assign get company-scoped validation first (ticket 01, agent SecScope already running).
- **Q10 `SearchSelect` keeps the chosen value while the user types; it changes only on a new choice or the × button.**
- **Q11 Inventory Requests list gets a "Tanggal Dibutuhkan" `DateRangePicker` filter (`needed_from`/`needed_to` already accepted by the server).**
- **R1 Tickets by module, not by kind (revises Q7).** Every page will change for dates, pickers, language and badges at once; splitting by kind would put several agents on the same files. Foundation tickets 02–03 first, then one ticket per sidebar group (04–09) in parallel, each owning its pages, controllers, requests, notifications and E2E specs, then docs (10) and QA (11).
- **R2 Month and time:** `ui/MonthPicker` (year switcher + 12-month grid, value `Y-m`) for the invoice generation period; `ui/TimeInput` (typed `HH:mm`, 24 h, popover of 30-minute slots) for WhatsApp quiet hours.
- **R3 Validation translations written by hand** (`lang/id/{validation,auth,passwords,pagination}.php` plus `lang/id.json` for JSON strings): no new library (AGENTS.md needs owner approval for one; the content is small and well known). `config/app.php` default and fallback locale `id`, `.env.example` / `.env.docker.example` `APP_LOCALE=id`; real `.env` files are the owner's (deploy note). `APP_FAKER_LOCALE` unchanged.
- **R4 Server-side search contract (Inertia-as-Island, no fetch/axios):** backend helper `App\Support\SearchOptions` returns `Inertia::optional(fn () => …)` props named `<field>Options`, filtered by a request param `<field>_search` (≥ 2 chars, `LIKE` escaped, company-scoped by the model's global scope, `limit(20)`, fields `value`, `label`, `description`). Frontend composite `RemoteSearchSelect` (built on `ui/SearchSelect` with new props `onSearch`, `loading`, `minChars`) debounces 300 ms and calls `router.reload({ only: ['<field>Options'], data: { <field>_search: q }, preserveState: true, preserveScroll: true, replace: true })`; the page passes the current value's option (`selected`) so the label shows before any search. Same pattern already used by geocode and regions on Customers/Create.
- **R4a Tenant rule for searchable options:** `SearchOptions` never builds its own query; each caller passes an explicitly company-scoped base query. Models under `BelongsToCompany` are scoped by their global scope, but `User` is exempt (AGENTS.md), so every user/employee/technician/handler/acquirer lookup joins `company_user` for `CompanyService::currentId()`, plus the role or eligibility filter the existing lists use (`DispatchQueueQuery::eligibleTechnicians/eligibleHandlers`, `TechnicianPerformanceQuery::eligibleTechnicians`, `CompanyMembershipService`). `SearchOptionsTest` includes a case where a company-B user never appears in company A's options. Note: `router.reload({ data })` adds `?<field>_search=…` to the URL even with `replace`; this is accepted, never "fixed" with fetch.
- **R5 Status maps:** files per domain (`customer.ts`, `subscription.ts`, `invoice.ts`, `payment.ts`, `workOrder.ts`, `ticket.ts`, `inventory.ts`, `network.ts`, `odn.ts`, `ipam.ts`, `people.ts`, `evaluation.ts`, `numbering.ts`), each `export const X: Record<string, { label: string; tone: BadgeTone }>` plus `optionsOf(map)` for filters; `ui/EnumBadge` `({ map, value })` renders the badge and falls back to a neutral badge showing the raw value (never crashes on an unknown value). Labels follow `docs/business/*.md` state names where they exist. Examples: `active` Aktif (success), `pending` Menunggu (warning), `suspended` Ditangguhkan (warning), `terminated` Berhenti (neutral), `in_progress` Dikerjakan (info), `waiting_review` Menunggu review (warning), `completed` Selesai (success), `cancelled` Dibatalkan (neutral), `open` Terbuka, `assigned` Ditugaskan, `on_progress` Dikerjakan, `resolved` Diselesaikan, `closed` Ditutup, `paid` Lunas, `partial` Sebagian, `overdue` Lewat jatuh tempo, `unpaid` Belum dibayar, customer type Individual → Perorangan, Company → Perusahaan.
- **R6 Copy glossary** (shared, enforced in review): Simpan, Batal, Hapus, Buat, Ubah, Kembali, Cari…, Ekspor CSV/Excel/PDF, "Baris per halaman", "Sebelumnya"/"Berikutnya", "Halaman {n} dari {m}", "Menampilkan {a}–{b} dari {total}", "Tidak ada data.", "Hapus data ini?", kata sandi, pelanggan, langganan, tagihan, pembayaran, barang, lokasi, aset, teknisi, karyawan, pengguna, peran, hak akses. Form titles "Buat {Entitas}", "Ubah {Entitas}", detail "{Entitas} {kode}".
- **R7 Known UI defects** that are broken today are fixed by the module ticket that owns the page, so the guide's caveats can be removed in ticket 10. The list: Lokasi "Tabel" crash; Employees edit never saves; Vehicles preload and pagination; Documents Active and Code; Organizations delete orphaning employees; product "Recent Movements" empty; Unit delete not checking categories; Evaluasi pagination; the dead "Kritis" priority; invoice status filter values; "Export Excel" returning CSV. The missing Stok write screens (issue, transfer, break-glass adjust) are new features, not defects: parked in `docs/PARKING_LOT.md`, and the guide keeps that caveat.
- **R8 Dates on the server:** form requests for every converted field use `date_format:Y-m-d` (date-time `Y-m-d H:i`, month `Y-m`, time `H:i`).
- **R9 Out of scope:** the Android apps, database content (seeded names such as ticket categories), and the SLA question raised on 2026-10-14 (separate grilling thread; ticket 04 does not change SLA tier behaviour, only its language).

## Testing decisions

- Selfchecks: date/month/time parse and format helpers; `optionsOf`/`EnumBadge` fallback; copy-lint script `resources/js/lib/copy.selfcheck.mjs` that scans `Pages/**` and `Components/**` for a denylist of English UI words in JSX text and common props (`label=`, `placeholder=`, `title=`) outside the kept-terms list, run in QA (allowlist for intentional English).
- PHPUnit: request validation for every changed field (bad format → 422 with the Indonesian message), `SearchOptions` (min chars, limit, company scope, LIKE escaping), report filter scoping (ticket 01), tests that assert English validation/flash text updated to Indonesian.
- E2E: each module ticket updates its specs; new `ui-pickers.spec.ts` covers DatePicker typing + calendar, RemoteSearchSelect search/pick/keep-value, MonthPicker, TimeInput, EnumBadge labels on one list page.
